# Квартал — игра для 2–4 друзей

Есть два режима: за одним компьютером и по сети. Сетевая партия работает через Node.js-сервер: он проверяет ходы, бросает кубики, сохраняет состояние и передаёт изменения всем участникам.

## Запуск на этом компьютере

Дважды нажмите `START-GAME.cmd`, затем откройте **http://localhost:3000**. Окно запуска должно оставаться открытым. Остановка — **Ctrl+C**. Если сервер уже запущен, просто откройте адрес.

Файл запуска использует готовую сборку. После изменения исходников нужно снова выполнить `npm run build`. На другом компьютере установите Node.js 22 с https://nodejs.org (вместе с npm). На этом компьютере запускающий файл также умеет находить встроенный Node.js приложения Codex.

Обычный запуск из папки, где лежит `package.json`:

```powershell
npm ci
npm run build
npm start
```

`npm ci` нужен при первой установке и после изменения зависимостей. Для последующих запусков достаточно `npm start`. Открывать `index.html` двойным нажатием не нужно.

## Игра через интернет

Google Диск можно использовать для хранения резервной копии архива проекта, но он не запускает игровой сервер. Веб-хостинг Drive был закрыт: [сообщение Google](https://workspaceupdates.googleblog.com/2016/07/reminder-turn-down-of-google-drive-web.html). Для этой версии подготовлен Render.

Размещение на постоянном адресе описано по шагам в **[DEPLOY-RENDER.md](DEPLOY-RENDER.md)**. Конфигурация Render уже находится в `render.yaml`. Публичный адрес появится после создания сервиса в вашем аккаунте Render.

После размещения:

1. Откройте адрес сайта и нажмите **«Играть онлайн»**.
2. Введите имя и нажмите **«Создать комнату»**.
3. Нажмите **«Копировать ссылку»** и отправьте её друзьям.
4. Друзья открывают ссылку со своих устройств и вводят имена.
5. Когда подключатся 2–4 игрока, создатель нажимает **«Начать сетевую игру»**.

Каждый управляет только своим игроком. Цвет и фишка назначаются автоматически. Все действия, аукционы и обмены синхронизируются; принять обмен может только его получатель. Панель разработчика в сетевой игре отключена.

**Возвращение:** откройте ссылку комнаты в том же браузере и нажмите «Вернуться в комнату». На главной странице также есть кнопка возвращения в последнюю комнату. При кратком обрыве связи открытая вкладка переподключается сама. Повторная доставка команды не делает второй ход.

Не очищайте данные сайта и не используйте приватный режим, если хотите позже вернуться: браузер хранит ключ вашего места. Открытие игры в другой вкладке переносит управление туда. Ушедшего игрока автоматически не заменяет бот; если настала его очередь, остальные ждут. До начала партии при потере места участником можно создать новую комнату.

Комнаты хранятся на сервере. Комната удаляется после семи дней без действий, когда к ней никто не подключён. Для сохранения после перезапуска хостинга обязателен постоянный диск. Локальная игра сохраняется отдельно, в браузере.

## Управление

- Броски, покупка, аукционы и обмен находятся в центре поля.
- Полная пастельная заливка обозначает цветовую группу; внешний флажок — владельца.
- Нажмите на свою улицу для строительства, продажи зданий, залога или снятия залога. Доступны только разрешённые операции.
- Перед движением кубики перебирают значения секунду; фишка идёт примерно по 0,32 секунды на клетку. При системной настройке уменьшения движения анимация пропускается.
- При двух участниках их карточки справа, при четырёх — по две с каждой стороны.

## Разработка и проверки

Для разработки запустите `npm run build:server` и `npm start` в первом терминале, `npm run dev` — во втором. Интерфейс разработки находится на http://localhost:5173 и передаёт сетевые подключения серверу на порту 3000. После изменения серверного кода пересоберите и перезапустите сервер.

```powershell
npm run typecheck
npm test
npm run lint
npm run build
npx playwright install chromium
npm run test:e2e
npm run test:e2e:online
```

Для установленного Chrome можно задать `$env:PLAYWRIGHT_CHANNEL='chrome'` перед E2E. Сетевые E2E используют готовую production-сборку. Запускайте два набора E2E по очереди.

## Устройство проекта

- `src/game` — игровой движок; `src/data` — поле и карты.
- `src/features` — интерфейс; `src/online` — протокол, соединение и комната ожидания.
- `server` — HTTP/WebSocket-сервер и хранение комнат.
- `data` — серверные сохранения при локальном запуске; не загружайте эту папку в репозиторий.

Сервер слушает `PORT` (по умолчанию 3000); сохранения записывает в `DATA_DIR` (по умолчанию `data`). `PUBLIC_ORIGIN` — необязательный точный адрес сайта, например `https://game.example.com`, если прокси меняет заголовок Host. По умолчанию WebSocket разрешён только с того же адреса, что и сайт.

Хранение рассчитано на **один экземпляр сервера**, максимум 100 комнат и 256 подключений. Для небольших партий друзей. Для горизонтального масштабирования понадобится общее хранилище и координация между серверами. Dockerfile и compose.yaml подготовлены как альтернативный способ запуска; контейнер в этой среде не проверялся.
