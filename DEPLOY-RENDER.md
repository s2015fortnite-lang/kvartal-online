# Как разместить «Квартал» на Render

Сетевая версия готова к размещению. Эта инструкция создаёт постоянную HTTPS-ссылку: компьютер создателя комнаты после размещения не должен работать как сервер.

## Что понадобится

Аккаунты GitHub и Render. В конфигурации выбран **платный Web Service с постоянным диском 1 ГБ**. Бесплатный тариф Render не поддерживает такой диск. Перед созданием сервиса проверьте итоговую стоимость в Render; оплата здесь не выполнялась. [Документация о дисках](https://render.com/docs/disks).

## 1. Загрузите проект в GitHub

1. Войдите на https://github.com и создайте новый репозиторий, например `kvartal-online`. Можно выбрать **Private**.
2. Распакуйте подготовленный архив `kvartal-render.zip`.
3. На странице репозитория выберите загрузку существующих файлов (**uploading an existing file** / **Add file → Upload files**).
4. Перетащите **содержимое** распакованной папки в GitHub, сохраняя вложенные папки, и сохраните изменения (**Commit changes**).
5. Убедитесь, что `package.json` и `render.yaml` видны прямо в корне репозитория, а рядом есть папки `src`, `server`, `scripts`. Сам ZIP загружать вместо исходников не нужно.

В архиве нет зависимостей, игровых сохранений и личных ключей. Если загружаете проект вручную из рабочей папки, не загружайте `node_modules`, `data`, `dist`, `server-dist`, `test-results` и `.env`.

## 2. Создайте сервис в Render

1. Войдите на https://dashboard.render.com.
2. Выберите **New → Blueprint**.
3. Подключите GitHub и разрешите Render доступ к репозиторию игры.
4. Выберите репозиторий; путь конфигурации — `render.yaml`.
5. Проверьте предложенную конфигурацию и стоимость: один сервис `kvartal-online`, регион Frankfurt, вычислительный план `0.5c-512mb`, постоянный диск 1 ГБ.
6. Подтвердите создание и дождитесь успешной сборки со статусом **Live**.

Blueprint автоматически задаёт сборку, запуск и путь сохранений. [Формат конфигурации Render](https://render.com/docs/blueprint-spec).

Если используете обычный **New → Web Service**, задайте эквивалентные настройки:

| Настройка | Значение |
| --- | --- |
| Runtime | Node |
| Build Command | `npm ci --include=dev && npm run build` |
| Start Command | `npm start` |
| Health Check Path | `/health` |
| NODE_VERSION | `22` |
| NODE_ENV | `production` |
| DATA_DIR | `/var/data/kvartal` |
| Disk mount path | `/var/data` |
| Disk size | 1 GB |
| Instances | 1 |

## 3. Откройте сайт и пригласите друзей

В карточке сервиса появится HTTPS-адрес вида `https://имя-сервиса.onrender.com`. Откройте его. Свой домен покупать необязательно.

Нажмите **«Играть онлайн» → введите имя → «Создать комнату»**. Скопируйте ссылку комнаты и отправьте друзьям. Когда все войдут, нажмите **«Начать сетевую игру»**.

Render поддерживает WebSocket-соединения на том же публичном адресе. Дополнительный открытый порт для игры не нужен. [Документация WebSocket](https://render.com/docs/websocket).

## Проверка после размещения

- Откройте сайт в двух разных браузерах или на двух устройствах; войдите в одну комнату.
- Сделайте бросок: оба должны увидеть одинаковый результат.
- Обновите страницу одного игрока, нажмите «Вернуться в комнату»: имя, деньги и позиция должны сохраниться.
- До серьёзной партии сделайте ручной перезапуск сервиса Render и убедитесь, что оба игрока возвращаются в прежнюю комнату. При обычном обрыве соединения открытые вкладки восстанавливаются автоматически.

## Обновления и сохранения

Автоматическое развёртывание по каждому изменению выключено, чтобы не перезапускать игру посреди партии. После загрузки новой версии в GitHub откройте сервис Render и выберите **Manual Deploy → Deploy latest commit**.

Партии сохраняются в `/var/data/kvartal`. Не удаляйте диск, не меняйте `DATA_DIR` без переноса данных и не увеличивайте число экземпляров сервера. При обновлении возможен короткий перерыв соединения; сохранённые партии остаются на диске. [Ограничения дисков](https://render.com/docs/disks).

## Если возникла проблема

- **Сборка упала:** проверьте, что исходники и `package-lock.json` загружены целиком, Node.js — 22, а `package.json` лежит в корне. Посмотрите первую ошибку во вкладке Logs.
- **Сайт открылся, но комната не создаётся:** нужен Web Service, не Static Site. Проверьте HTTPS и соединение с `/ws`.
- **WebSocket отклонён прокси:** добавьте `PUBLIC_ORIGIN` с точным HTTPS-адресом вашего сайта, без завершающего `/`, и перезапустите сервис.
- **После перезапуска нет партии:** проверьте наличие постоянного диска и совпадение его пути с `DATA_DIR`.
- **Не получается вернуться в начатую партию:** откройте ту же ссылку в том же браузере. В другом браузере нет ключа прежнего игрока.

Пока сервис не создан в вашем аккаунте, публичной ссылки ещё нет. Готовы код, конфигурация и локальные проверки; создание платных ресурсов выполняется вами в Render.
